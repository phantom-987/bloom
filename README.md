An interactive sunflower garden that grows and blooms in response to your hand — no mouse, no keyboard, just a webcam.

**Spread your thumb and index finger apart to grow the stems. Pinch them together to bloom the flowers.**

Two independent implementations of the same idea, sharing the same rendering logic and visual language:

| File | Runs on | Stack |
|---|---|---|
| `index.html` | Browser | HTML5 Canvas + MediaPipe Hands (JS) |
| `sunflower.py` | Desktop | OpenCV + MediaPipe (Python) |
